Política de privacidade

Última atualização: 18 de novembro de 2026

A Fábrica de Shorts é uma ferramenta de uso pessoal: roda no computador do próprio autor e é usada apenas por ele, nos canais dele.

Dados acessados

Com a autorização do dono do canal (escopo youtube.upload da API do YouTube), a ferramenta envia vídeos e define título, descrição, tags e horário de publicação. Ela não lê, coleta nem armazena dados de espectadores, comentários, mensagens ou de qualquer outra conta.

Armazenamento

O token de acesso fica salvo apenas no computador do autor, num arquivo local, e não é enviado a servidores da ferramenta (não há servidores da ferramenta). Nenhum dado é vendido, compartilhado ou usado para publicidade.

Uso de dados de APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. O uso do YouTube também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
